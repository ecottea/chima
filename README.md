# ✨ アナグラム／チマタグラムクイズ

文字を並べ替えて答えを当てる、ブラウザで遊べる日本語クイズです。通常のアナグラムに加え、答えに含まれない文字が **1 文字だけ** 混ざる「チマタグラム」を出題します。ジャンルを選んで、問題を順番・指定番号・ランダムで楽しめます。

## 遊び方

1. **問題セット**から出題ジャンルを選びます。
2. 表示された文字列と読みを手掛かりに、元の言葉を考えます。
   - 「チマタグラム」では、文字列に余計な文字が 1 文字含まれます。
   - 「アナグラム」では、余計な文字は含まれません。
3. `💡 答えを見る` を押すと、答えを確認できます。チマタグラムでは余計な 1 文字も表示されます。
4. `前の問題へ`、`次の問題へ`、問題番号入力、または `🎲 ランダム` で次の出題に進みます。

## 収録している問題セット

| 問題セット | 形式 | データファイル |
| --- | --- | --- |
| ノンジャンル | アナグラム | `data/non_genre_anagram.json` |
| ノンジャンル | チマタグラム | `data/non_genre.json` |
| ポケモンの名前 | チマタグラム | `data/pokemon_names.json` |
| ポケモンの技 | チマタグラム | `data/pokemon_moves.json` |
| ポケモンの特性 | チマタグラム | `data/pokemon_abilities.json` |

## 起動方法

依存パッケージやビルドは不要です。ただし、問題データを `fetch` で読み込むため、`index.html` を `file://` で直接開かず、ローカル Web サーバー経由で開いてください。

```bash
cd /workspace/chima
python3 -m http.server 8000
```

起動後、ブラウザで [http://localhost:8000](http://localhost:8000) を開きます。

## 主な機能

- 問題セットの切り替え
- 前回選んだ問題セットと、セットごとの進捗番号のブラウザ保存
- 問題番号を指定して移動（入力欄で Enter でも移動可能）
- 同じ問題が連続しないランダム出題
- 備考欄に含まれる URL のリンク表示
- 画面幅に合わせたシンプルなブラウザ UI

## データ形式

各問題セットは JSON の配列です。チマタグラムでは `extraChar` を指定し、アナグラムでは省略します。ノンジャンルの問題では、必要に応じて `answerReading` や `remarks` も利用できます。

```json
{
  "id": 1,
  "genre": "ゲーム",
  "question": "ほう、例題助かるー",
  "reading": "ほうれいだいたすかるー",
  "answer": "崩壊：スターレイル",
  "answerReading": "ほうかいすたーれいる",
  "extraChar": "だ",
  "remarks": "任意の補足情報"
}
```
